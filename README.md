# <img alt="app icon" src=".github/assets/app_icon.svg" width="48" /> mpvNC
A media player for Android based on [mpv-android](https://github.com/mpv-android/mpv-android), forked from [mpvKt](https://github.com/abdallahmehiz/mpvKt) and customized by **ShuhaibNC**.

[![Build](https://github.com/ShuhaibNC/mpvNC/actions/workflows/build.yml/badge.svg)](https://github.com/ShuhaibNC/mpvNC/actions/workflows/build.yml)

## Features
- Nicer player UI with a **YouTube-style theme** (red seekbar + slim progress strip when controls are hidden)
- **Video folders home screen** — browse folders containing videos (list or grid view), tap a folder to see its videos, tap to play
- Quick **+ open button** in the top bar for opening a URL or picking a file
- Better playback history implementation
- Easier customization, including an **8-color accent palette** in Appearance
- Sleep timer, Speed presets
- Smoother PiP
